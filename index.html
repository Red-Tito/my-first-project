03. Signal Flow

Step-by-step path data takes from source to viewer

# Stage From To Protocol / Format Notes
1 Camera Capture Studio & Remote Cameras ATEM Constellation SDI 12G 4K/UHD or HD depending on channel standard
2 Remote Contribution Field LiveU Units LiveU Server → ATEM LRT / SRT Bonded cellular via LiveU cloud infrastructure
3 Data Ingest Electoral Commission API Data Aggregator → Viz Trio REST / JSON Polled every 30–60 s; auto-triggers graphic updates
4 Graphics Render Viz Trio Templates ATEM via fill + key SDI (RGBA) Clean key over video; animated data bars and maps
5 Virtual Set Unreal Engine ATEM (downstream key) NDI / SDI Camera tracking via zero-latency encoder
6 Vision Mixing ATEM Constellation Master Control Room SDI 12G Program, preview, and multiviewer outputs
7 Audio Mix Yamaha QL5 MCR (embedded into SDI) AES / AES67 Mix minus for remote guests; IFB to presenters
8 ISO Recording ATEM multi-output HyperDeck Studio H.265 / ProRes All ISO feeds recorded for post and legal archive
9 Broadcast TX MCR Program Out Transmitter / Uplink DVB-T / DVB-S2 Primary over-the-air and satellite path
10 OTT Packaging MCR Program Out AWS MediaLive → CDN HLS / DASH Sub-30 s latency for web and mobile streaming
11 Social Clips HyperDeck Archive Newsroom / Social Team H.264 MP4 Auto-clipped highlights pushed to digital team

04. Election Night Workflow

Four stages from preparation to live output

01
Pre-Production
T-72 h to T-4 h before polls close
  • Load constituency templates into Viz Trio
  • Configure data API polling for electoral commission
  • Set up and test virtual studio environment in Unreal
  • Commission remote LiveU units at counting centres
  • Prepare ATEM macros for common transitions
  • Rehearse touchscreen data wall with presenter
02
Build-Up Coverage
T-4 h to polls close
  • Go live with studio programme — pre-analysis
  • Confirm all remote camera signals active
  • Run Viz Mosart automation dress rehearsal
  • Activate OTT stream; verify CDN delivery
  • Social team begins short-form content output
  • Technical checks on audio IFB for field crews
03
Live Results Night
Polls close → final seat called
  • Data API triggers automatic graphic updates in Viz Trio
  • Director calls shots via ATEM with Mosart assist
  • Results maps updated on touchscreen data wall
  • Remote live shots cut in from counting centres
  • Breaking results lower-thirds pushed in real time
  • HyperDecks record all ISO feeds continuously
04
Post-Production Wrap
Final seat called → T+6 h
  • Final results package rendered and archived
  • Clip team exports highlights for social platforms
  • All ISO recordings transferred to NAS storage
  • Debrief: flag any data sync issues for next time
  • OTT stream kept live for VOD replay window
  • Equipment strike and kit return to stores
